# AquaSense – Automated Plant Watering System

## Project Overview

AquaSense is an ESP32-based automated plant watering system designed to monitor soil moisture and automatically control a water pump based on the moisture level of the soil.

## Features

- Real-time soil moisture monitoring
- Automatic water pump control
- OLED display for moisture readings
- ESP32-based control system
- Helps reduce unnecessary water usage

## Components Used

- ESP32
- Soil Moisture Sensor
- Relay Module
- Water Pump
- OLED Display (SSD1306)
- Breadboard
- Connecting Wires

## Technologies Used

- ESP32
- Arduino IDE
- Embedded C/C++
- IoT
